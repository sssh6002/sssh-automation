    2. 
      
  2. 下載公文與附件到本機
    3. 
      
  3. 逐份產生摘要（會叫 AI，花 token）
    4. 
    

    
執行中會自己開一個 Chrome 視窗操作 edoc，請不要動滑鼠鍵盤，也不要關那個視窗。
      需要插著自然人憑證。9 份大約 3～5 分鐘。

    
不會擬辦、不會送陳核、不會貼校網。

    

      
      
    

  






  

    
確定要送出這些公文嗎？

    
送出去就收不回來。下面每一筆的擬辦都會填進 edoc、
      按「陳會」、用你的自然人憑證簽章。請最後看一次實際會送出的字。

    

    
過程中會操作 Chrome，請不要動滑鼠鍵盤。憑證要插著、螢幕不能鎖。
      任何一筆出錯會整批停下來，已送出的不會重送。

    

      
      
    

  






  

    
確定要把這些公文歸檔嗎？

    
歸檔之後，沒有 admin 介入就救不回來。
      下面每一筆會被歸到框起來的那個檔號、用你的自然人憑證簽章。
      檔號歸錯要找 admin 才能改，請最後看一次。

    

    
過程中會操作 Chrome，請不要動滑鼠鍵盤。憑證要插著、螢幕不能鎖。
      任何一筆出錯會整批停下來，已歸檔的不會重做。

    
這一段不會貼校網。要公告的走「張貼」那一頁逐筆確認。

    

      
      
    

  







  

    
要重產這一筆的文案嗎？

    
現在這一篇會被整篇換掉。
      你自己改過的字會不見，而且救不回來 —— 要留的話，先按「取消」再按「複製全文」存起來。

    

    
重產會叫一次 AI（花 token），大約十幾秒。
      不會把任何東西貼上校網，也不會動 edoc。

    

      
      
    

  







  

    
確定要把這些公告貼上校網嗎？

    
貼出去全校師生家長都看得到。
      這是整套流程裡唯一真的對外的一步。貼錯可以事後刪，但已經被看到就是被看到了。
      請最後看一次每一篇的標題、分類、附件，以及整篇內文。

    

    
程式會自己開一個 Chrome 登入校網填表單，請不要動滑鼠鍵盤。
      這一段不碰 edoc、不用插卡。任何一筆出錯會整批停下來，已貼出的不會重貼。
